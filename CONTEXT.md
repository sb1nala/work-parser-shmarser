# Vacancy Bot

Личный Telegram-бот, который собирает стажировки по аналитике и ML с hh.ru и карьерных сайтов банков, отсеивает неподходящие и показывает владельцу новые.

## Language

**Объявление** (Posting):
Одна публикация вакансии в одном источнике.
_Avoid_: вакансия (так называется склеенная), пост, лот

**Вакансия** (Vacancy):
Склеенная запись: одна на набор открытых объявлений с одним ключом.
_Avoid_: объявление, позиция

**Источник** (Source):
Сайт, откуда берутся объявления, и его адаптер (hh, tbank, sber).
_Avoid_: парсер, площадка

**Решение** (Decision):
Результат работы фильтра по объявлению: принято или нет, причина отсева и флаги неизвестных полей.
_Avoid_: вердикт, оценка

**Статус** (Status):
Отметка владельца о вакансии: новая, интересная, скрытая, отклик отправлен.
_Avoid_: состояние, стадия

**Тихий запуск** (Quiet run):
Первый запуск, при котором найденное записывается в базу без уведомлений.
_Avoid_: сухой прогон, холодный старт

**Бэклог** (Backlog):
Вакансии, накопленные при тихом запуске, которые владелец разбирает позже.
_Avoid_: очередь, архив

**Переоткрытая** (Reopened):
Вакансия, чей ключ снова появился в источнике после закрытия.
_Avoid_: повторная, дубль
